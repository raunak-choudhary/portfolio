# Licences for the deep-sky photographs

These are the eight galaxy and nebula photographs shown far behind the route in the admin dashboard's star field (the owner removed the black hole, and the set was cut from thirteen to eight so each one is noticed). Every file comes from Wikimedia Commons. The credits and licences below come from each file's Commons page, fetched on 2026-11-12. No film stills, stock photos or generated images are used.

Every file here is a derived work. The source (a Commons original, or Commons's 3840 px rendition when the original was larger than about 4000 px or 20 MB) was resized with macOS `sips` and encoded to WebP in Chromium: `<slug>.webp` is 1024 px on the long side, `<slug>-512.webp` is 512 px. Aspect ratios are unchanged and nothing is cropped beyond what the Commons file already had. Colours are as published.

Public domain here means a work of NASA, which carries no copyright in the United States. NASA asks to be credited, and the credit is kept below. CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/) requires the credit line, a link to the licence and a note that changes were made. Use the credit line exactly as given.

Notes:

- Andromeda is NASA's Galaxy Evolution Explorer (GALEX) ultraviolet mosaic of M31 (NASA photojournal PIA15416), stitched from 11 fields, in the rotated version on Commons. It is an ultraviolet view, not visible light, so the spiral arms read as blue-white rings. A few dark notches at the left and lower-right edges are gaps between mosaic fields and were left uncropped. It replaces an earlier amateur photograph so that every image here is space-agency work.
- The Pinwheel file is labelled CC BY 4.0 on Commons (an ESA/Hubble release, heic0602), so it is treated as CC BY 4.0, not public domain.
